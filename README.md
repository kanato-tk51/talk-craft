# Talk Craft

外部の対話AIを使った英会話学習の「予習・実践・復習」をつなぐ、プロバイダー非依存の学習管理Webアプリです。

## 現在の実装範囲

最初の縦切りとして、次を実装しています。

- 英会話セッションの作成と一覧・詳細表示
- テーマと任意の目的から会話開始用プロンプトを生成
- セッションから独立した表現ライブラリの登録・編集・削除
- 表現とセッションの任意の関連付け（会話の前後で変更可能）
- 汎用の会話開始／振り返り出力プロンプトの生成とスナップショット保存
- 外部AIサービスへ持ち出すプロンプトのコピー
- YouTube URLから英語字幕を取得し、ChatGPTへ貼り付ける翻訳プロンプトを生成
- ChatGPTの回答JSONを取り込み、自然な意味段落・日本語訳・重要表現を登録
- 原文・段落・時刻・注釈位置をアプリ側で検証

JSONインポートと復習編集は設計済みです。本番認証はCloudflare Accessで本人だけを許可し、アプリ側でもAccess JWTを検証します。

## ローカル起動

```bash
npm install
npm run db:migrate
npm run dev
```

ローカルDBはCloudflare D1互換のSQLiteとして`.wrangler/state`に作成され、開発ユーザーは初回アクセス時に自動登録されます。`http://localhost:3000`を開いてください。詳しい前提とトラブルシュートは[ローカル開発環境](docs/product-design.md#21-ローカル開発環境の構築手順)を参照してください。

## YouTube教材の使い方

1. ヘッダーの「YouTube教材」から「動画を取り込む」を選び、英語字幕が公開されたYouTube動画のURLを貼り付けます。
2. Talk Craftが作成したプロンプトをコピーしてブラウザ版ChatGPTへ貼り付けます。
3. ChatGPTの回答JSONをTalk Craftへ戻すと、日本語訳と重要表現を検証して登録します。
4. 英語原文と日本語訳を時間付きで見比べ、原文中の赤い下線付き表現をクリックして、右側のコメントパネルで意味・ニュアンス・例文を確認します。長い表現も通常文と同じように自然に折り返されます。
5. 原文中の任意の文字列をドラッグ選択し、自分で重要だと思った表現を赤い注釈として追加できます。ChatGPTが挙げた表現も自分で追加した表現も、解説パネルから削除できます。
6. 教材詳細の埋め込みプレーヤーで動画を再生できます。不要になった教材は確認ダイアログから字幕・翻訳・重要表現ごと削除できます。

YouTubeの公式Captions APIによる字幕ダウンロードは動画を編集できるユーザーの認可が必要なため、この機能は公開ページから取得できる字幕情報を利用します。英語字幕は動画投稿者が作成した字幕を優先し、それがない場合に自動生成字幕を使用します。非公開・年齢制限・地域制限のある動画、字幕が公開されていない動画、YouTube側で取得を制限された動画には対応できません。取得処理は非公式の公開インターフェースに依存するため、YouTubeの変更に合わせた保守が必要です。
